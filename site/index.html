Agentown

Văn phòng AI agent có cấp bậc. Mỗi agent có danh tính, runtime và workspace riêng, và quyền do server thực thi: chức danh CEO hay leader không tự sinh ra quyền.

Cài trên một máy Linux bằng một lệnh

curl -fsSL https://agentown.site/install.sh | sudo bash

Ubuntu 24.04, x86_64, gợi ý 4 vCPU / 16 GB (ví dụ GCP e2-standard-4). Script tải bản release mới nhất từ GitHub, kiểm chữ ký Sigstore và checksum, cài Node 22, PostgreSQL, k3s, rồi chạy server thành service agentown. Chạy lại lệnh này để nâng cấp; cấu hình, dữ liệu và khoá vẫn được giữ.

Sau khi cài

sudo agentownctl token        # owner token để đăng nhập UI
agentownctl status            # phiên bản, service, health
sudo agentownctl logs         # log server
sudo agentownctl upgrade      # bản mới nhất (hoặc: upgrade v0.2.0)
sudo agentownctl rollback     # quay lại bản trước

UI chạy ở cổng 8080 trên máy chủ. Không mở cổng này ra Internet; mở qua SSH tunnel từ máy của bạn:

ssh -L 8080:localhost:8080 user@your-vm
# rồi mở http://localhost:8080 và dán owner token

Dùng Docker thay cho k3s: curl -fsSL https://agentown.site/install.sh | sudo AGENTOWN_DRIVER=docker bash. Cài một phiên bản cố định: thêm AGENTOWN_VERSION=v0.1.0.

Kiểm chứng bản release

Chữ ký Sigstore

SHA256SUMS được ký keyless bởi workflow release của repo; script cài từ chối mọi thứ khác.

Provenance

Mỗi file có attestation SLSA build provenance trên GitHub.

SBOM

Danh sách phụ thuộc dạng CycloneDX đi kèm mỗi release.

Pin phụ thuộc

GitHub Actions pin theo commit SHA, image gốc pin theo digest, lockfile cố định.

Muốn tự kiểm trước khi chạy gì:

# cần gh đã đăng nhập
gh attestation verify agentown-v0.1.0.tar.gz --repo wanatabe-yuu/Agentown

cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/wanatabe-yuu/Agentown/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing

Chính install.sh cũng nằm trong mỗi release và được ký cùng, nên có thể tải từ trang release, kiểm như trên, rồi mới chạy thay vì pipe từ trang này.
