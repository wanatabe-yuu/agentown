Agentown

An office of AI agents with a real hierarchy. Each agent has its own identity, runtime and workspace, and permissions enforced by the server: a title like CEO or leader grants nothing by itself.

Install on a Linux host with one command

curl -fsSL https://agentown.site/install.sh | sudo bash

Ubuntu 24.04, x86_64, 4 vCPU / 16 GB suggested (e.g. GCP e2-standard-4). The script downloads the latest release from GitHub, verifies its Sigstore signature and checksums, installs Node 22, PostgreSQL and k3s, and runs the server as the agentown service. Run it again to upgrade; config, data and keys are kept.

After installing

sudo agentownctl token        # owner token for signing in to the UI
agentownctl status            # version, service, health
sudo agentownctl logs         # server log
sudo agentownctl upgrade      # latest release (or: upgrade v0.2.0)
sudo agentownctl rollback     # back to the previous release

The UI listens on port 8080 on the server. Do not open this port to the Internet; reach it through an SSH tunnel from your own machine:

ssh -L 8080:localhost:8080 user@your-vm
# then open http://localhost:8080 and paste the owner token

Docker instead of k3s: curl -fsSL https://agentown.site/install.sh | sudo AGENTOWN_DRIVER=docker bash. A specific version: add AGENTOWN_VERSION=v0.1.0.

Verifiable releases

Sigstore signature

SHA256SUMS is signed keylessly by the repository's release workflow; the installer refuses anything else.

Provenance

Every file has a SLSA build-provenance attestation on GitHub.

SBOM

A CycloneDX list of dependencies ships with every release.

Pinned dependencies

GitHub Actions pinned by commit SHA, the base image by digest, a frozen lockfile.

To verify it yourself before running anything:

# gh must be logged in
gh attestation verify agentown-v0.1.0.tar.gz --repo wanatabe-yuu/Agentown

cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/wanatabe-yuu/Agentown/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing

install.sh itself is part of every release and signed with it, so you can download it from the release page, verify it as above, and run it instead of piping it from this site.
