# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code rather than people,
and make it welcoming for newcomers. Harassment and personal attacks are not
tolerated.

Report unacceptable behaviour privately to the maintainers through the
repository's private reporting channel (Security → "Report a vulnerability",
noting that it is a conduct report) or by contacting a maintainer directly on
GitHub. Reports are handled confidentially.
